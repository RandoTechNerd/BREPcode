18650: **18.6mm diameter x 65.2mm long** for a bare cell. A *protected* cell
carries a PCB on the negative end and runs to **69mm** — if the user has not
said which they have, size the length for 69mm and say so; a pocket cut for a
bare cell simply will not close on a protected one.

Pocket: **19.2mm bore, 70mm deep.** Wall 2.4mm minimum.

21700 for comparison: 21.4 x 70.5mm (pocket 22.0 x 72).

**Lithium safety, non-negotiable:**

- Leave a vent path. Never seal the cell into a closed pocket.
- Key the pocket or label polarity — a reversed lithium cell is a fire, not an
  inconvenience.
- 8mm at each end for contacts and a spring.

You have every dimension you need — build it.
