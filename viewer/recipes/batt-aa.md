AA (LR6): **14.5mm diameter x 50.5mm long.** Standard maximum, so design to it.

Pocket for a hand-swapped cell: **15.0mm bore, 51.5mm deep** (+0.5 diameter,
+1.0 length). Wall 2.4mm, floor 3mm.

Pitch when laying several side by side: **17mm centre-to-centre** with a 2.5mm
wall between bores (14.5 + 2.5 = 17.0).

You have every dimension you need — build it. Do not ask the user for cell
measurements.
