AAA (LR03): **10.5mm diameter x 44.5mm long.** That is the standard maximum, so
it is the number to design against.

Pocket for a hand-swapped cell: **11.0mm bore, 45.5mm deep** (+0.5 diameter,
+1.0 length). Wall 2.4mm, floor 3mm.

Pitch when laying several side by side: **13mm centre-to-centre** with a 2.4mm
wall between bores (10.5 + 2.5 = 13.0). Tighten to 12.5mm only if the wall
between them can drop to 2mm.

You have every dimension you need — build it. Do not ask the user for cell
measurements.
