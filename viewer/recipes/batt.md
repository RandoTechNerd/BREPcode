Sizes are nominal maxima from the IEC/ANSI standards; real cells vary by a few
tenths, and wrapped or protected cells run longer. Add clearance, never subtract.

| Cell | Diameter | Length |
|---|---|---|
| AA (LR6) | 14.5mm | 50.5mm |
| AAA (LR03) | 10.5mm | 44.5mm |
| C (LR14) | 26.2mm | 50.0mm |
| D (LR20) | 34.2mm | 61.5mm |
| 18650 | 18.6mm | 65.2mm (protected: up to 69mm) |
| 21700 | 21.4mm | 70.5mm |
| CR2032 coin | 20.0mm | 3.2mm thick |
| CR2016 coin | 20.0mm | 1.6mm thick |
| 9V (PP3) | 26.5 x 17.5mm | 48.5mm tall |

**Clearance**: +0.5mm on diameter, +1.0mm on length for a cell that must slide
in and out by hand. Cylindrical cells sitting in a channel want a slot rather
than a bored hole, so a fingertip can reach in.

**Rules that matter regardless of chemistry:**

- Never design a cavity that can seat a cell backwards if the contacts are
  live — either key the pocket or leave both ends open and label polarity.
- Leave 6-8mm at each end for a contact spring; a pocket cut to the exact cell
  length has nowhere for the electrics to go.
- Lithium cells (18650, 21700, LiPo) get a vent path. Do not fully encapsulate
  them in a sealed pocket.
- A cell that rattles will eventually break a solder joint — snug is safer than
  loose, so prefer +0.5mm over +1mm where the user will not swap it often.
