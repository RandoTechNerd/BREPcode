The open Gridfinity standard (Zack Freedman), the numbers that matter:

- Grid pitch: **42 × 42mm** per unit. A "2×3 bin" spans 84 × 126 nominal.
- Bin footprint: **41.5 × 41.5** per unit (0.5 total clearance), outer corners
  rounded **r 3.75**.
- Height unit: **7mm**. Bin height = u × 7 (a "3u" bin is 21 tall), measured
  including the base profile below.
- Base plinth profile, bottom-up: **0.8mm 45° chamfer → 1.8mm straight →
  2.15mm 45° chamfer** (4.75 total). One plinth per 42mm cell on multi-unit
  bins — that is what drops into the baseplate.
- Baseplate: the negative of that profile per cell; a simple printed baseplate
  is a 42-pitch grid of those sockets, 5mm tall overall.
- Magnets (optional): Ø6 × 2 discs in Ø**6.5** pockets, **2.4** deep, one per
  corner of each cell, centres 4.8 in from each cell edge. Press fit + a drop
  of CA; add a 0.4 cover layer to skip the glue.
- Screws (optional, instead of magnets): M3 through the same corner positions.

Simplifications that stay compatible: a bin that only needs to SIT on a
baseplate needs the plinth profile and footprint only; the stacking lip on top
(so bins stack on bins) can be approximated as a 45° chamfered rim ~4.4 tall
matching the base profile — say you approximated it if you do.

You have every dimension you need — build it.
